# Program artifacts

All three SPEL programs compile to real RISC Zero guest ELFs via the
docker builder (`make build` in each program directory). Guest deps are
pinned to `lee_core` tag `v0.2.4` (matching `spel-framework`'s `nssa_core`
dependency) and `enum-ordinalize 4.3.0` (risc0 zkVM toolchain is rustc
1.88).

## IDLs

Canonical IDLs are generated by `spel-framework::generate_idl!` and live at:

- `programs/registry/idl/registry-idl.json`
- `programs/testimonial/idl/testimonial-idl.json`
- `programs/pointer/idl/pointer-idl.json`

Regenerate either way:

```bash
# via the generated examples binary (host toolchain; guest build skipped
# because ELFs already exist)
cd programs/<name>
RISC0_SKIP_BUILD=1 cargo run -p <name>-examples --bin generate_idl > idl/<name>-idl.json

# or via the spel CLI (source-scan only)
spel generate-idl programs/<name> > idl/<name>-idl.json
```

## Rebuild

```bash
cd programs/<name>
make build   # docker risc0 guest build; prints the image ID
```
